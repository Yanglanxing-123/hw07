\## 运行方式

1\.  安装依赖：`pip install -r requirements.txt`

2\.  运行代码：`python train.py`



\## 实验说明

使用自建CNN模型对胸部X光影像进行二分类，区分正常与肺炎影像，输出训练曲线、混淆矩阵及准确率、召回率等指标。
