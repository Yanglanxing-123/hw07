# hw07.7z 分卷文件仓库

## 📌 仓库说明
本仓库存放了 `hw07.7z` 的分卷文件。
原文件大小约 **1GB**，因 GitHub 单文件上传限制（≤25MB），已使用 **7-Zip** 按 **24MB/个** 分卷存储，方便下载与还原。

---

## 📂 文件列表说明
所有分卷文件命名格式为：
- `hw07.7z.001`
- `hw07.7z.002`
- `hw07.7z.003`
- ...

⚠️ **重要提醒**：
1.  必须**下载全部分卷文件**，缺任何一个都无法还原完整文件。
2.  所有分卷文件必须放在**同一个文件夹**内，再执行还原操作。

---

## 🛠️ 还原方法（推荐：7-Zip 图形化操作）
### 1. 安装工具
先安装免费开源的压缩工具 7-Zip：
[7-Zip 官方下载地址](https://www.7-zip.org/)

### 2. 还原步骤
1.  将所有 `.001`、`.002`、`.003`… 分卷文件下载到同一个文件夹中。
2.  右键点击 **第一个分卷文件 `hw07.7z.001`**。
3.  在右键菜单中选择：`7-Zip` → `提取到当前文件夹`。
4.  等待解压完成，即可得到完整的 `hw07.7z` 文件，解压后可进一步获取其中的内容。
